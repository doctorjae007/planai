# KruPlan AI Starter

ชุดข้อมูลและข้อกำหนดเริ่มต้นสำหรับพัฒนาโปรแกรมสร้างแผนการจัดการเรียนรู้คณิตศาสตร์ ม.1-ม.3

## ขอบเขตปัจจุบัน

- รายวิชาคณิตศาสตร์พื้นฐาน ม.1-ม.3 ภาคเรียนที่ 1-2
- ภาคเรียนละ 60 ชั่วโมง (1.5 หน่วยกิต)
- Schema สำหรับมาตรฐาน ตัวชี้วัด หน่วยการเรียนรู้ และแผนหน้าเดียว
- เนื้อหารายภาคเรียนของคณิตศาสตร์ ม.1-ม.3 จากภาพอ้างอิงหลักสูตร สสวท.
- Checklist เบื้องต้นจากภาพสรุป 8 ตัวชี้วัด PA
- ยังไม่บรรจุข้อความมาตรฐานและตัวชี้วัดฉบับเต็ม เพราะต้องคัดจาก PDF ทางการ ฉบับปรับปรุง พ.ศ. 2560

## เริ่มใช้งาน

1. เปิดโฟลเดอร์นี้ใน VS Code
2. ให้ Codex อ่าน `docs/MASTER_SPEC.md`
3. ตรวจไฟล์ใน `data/` ก่อนสร้าง UI
4. อย่าให้ AI แต่งข้อความมาตรฐานหรือตัวชี้วัดเอง

## แหล่งข้อมูลที่ใช้แล้ว

- `โครงสร้างรายวิชา.pdf` จำนวน 4 หน้า
- ภาพสรุป 8 ตัวชี้วัด PA สำหรับการสอน 1 ชั่วโมง (ใช้เป็นแนวทางเบื้องต้นเท่านั้น)
- ภาพตัวอย่างแผนการจัดการเรียนรู้หน้าเดียว (ใช้เป็นแนวทางองค์ประกอบ ไม่คัดลอกงานออกแบบ)
- ภาพสรุปเนื้อหาคณิตศาสตร์ ม.ต้น แยกตามชั้นและภาคเรียน
