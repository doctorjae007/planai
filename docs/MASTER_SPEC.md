# MASTER SPEC: KruPlan AI

## 1. เป้าหมาย

สร้างเว็บแอปช่วยครูจัดทำแผนการเรียนรู้คณิตศาสตร์ ม.1-ม.3 ได้ทั้งภาคเรียน ตรวจความเชื่อมโยงระหว่างหลักสูตร จุดประสงค์ กิจกรรม การประเมิน และเกณฑ์ PA พร้อมส่งออกแผนฉบับเต็มและแผนหน้าเดียว

## 2. เทคโนโลยี

- React + Vite
- Tailwind CSS
- Supabase (ระยะเชื่อมฐานข้อมูล)
- Zod สำหรับตรวจ JSON
- docx สำหรับส่งออก Word
- Edge Function สำหรับเรียก AI โดยไม่เปิดเผย API key

## 3. ขั้นตอนผู้ใช้

1. สร้างภาคเรียนใหม่
2. เลือก ม.1, ม.2 หรือ ม.3 และภาคเรียน 1 หรือ 2
3. ระบบโหลดรหัสวิชา ชั่วโมง มาตรฐาน ตัวชี้วัด และหน่วยการเรียนรู้
4. ครูกำหนดจำนวนสัปดาห์ วันหยุด ชั่วโมงจริง และรูปแบบการสอน
5. ระบบสร้างโครงสร้างทั้งเทอมให้ตรวจสอบก่อน
6. ครูยืนยันโครงสร้าง
7. ระบบสร้างแผนเป็นชุด ชุดละไม่เกิน 5-10 แผน
8. ครูแก้ไขและตรวจ PA
9. ส่งออก Word, PDF หรือแผนหน้าเดียว PNG

## 4. กฎสำคัญ

- ห้ามสร้างข้อความมาตรฐานหรือตัวชี้วัดจากความจำ
- ใช้เฉพาะรายการที่ `verification_status` เป็น `verified`
- ระดับชั้นเป็นข้อกำหนดของหลักสูตร แต่ภาคเรียนเป็นโครงสร้างของสถานศึกษา
- ชั่วโมงรวมของหน่วยต้องเท่ากับชั่วโมงสอนจริงของภาคเรียน
- ทุกจุดประสงค์ต้องเชื่อมกับตัวชี้วัดอย่างน้อยหนึ่งรายการ
- ทุกจุดประสงค์ต้องมีหลักฐานและวิธีประเมินที่สอดคล้อง
- ครูต้องแก้ไขข้อมูลได้ก่อนส่งออก
- PA Checker เป็นเครื่องมือช่วยตรวจ ไม่รับรองผลการประเมินวิทยฐานะ

## 5. หน้าจอ MVP

- Dashboard
- Semester Setup
- Course Structure Editor
- Unit/Indicator Mapping
- Teaching Model Selector
- Semester Plan Preview
- Lesson Plan Editor
- PA Checker
- One-page Plan Preview
- Export Center

## 6. แผนการพัฒนา

### Phase 1

- สร้าง UI ด้วยข้อมูล JSON ในเครื่อง
- สร้างตัวเลือกชั้น/ภาคเรียน
- แสดงโครงสร้างรายวิชาและแบบฟอร์มแผน

### Phase 2

- นำเข้ามาตรฐานและตัวชี้วัดฉบับทางการ
- เพิ่มหน่วยการเรียนรู้และสาระการเรียนรู้แกนกลาง
- สร้างระบบตรวจข้อมูล

### Phase 3

- เชื่อม Supabase
- เพิ่มระบบผู้ใช้และบันทึกฉบับร่าง
- สร้างแผนด้วย AI ผ่าน Edge Function

### Phase 4

- PA Checker
- ส่งออก Word/PDF/PNG
- ทดสอบกับแผนจริงของโรงเรียนบ้านคูหา

## 7. Definition of Done สำหรับ MVP

- เลือกรายวิชา ม.1-ม.3 ได้ครบ 6 รายวิชา
- สร้างโครงสร้างภาคเรียน 60 ชั่วโมงได้
- เลือกและเชื่อมตัวชี้วัดที่ผ่านการตรวจสอบได้
- สร้าง/แก้ไขแผนรายคาบได้
- ตรวจ Alignment และ PA Checklist ได้
- ส่งออกแผนหน้าเดียวและ Word ได้โดยข้อความไม่ตกหล่น
